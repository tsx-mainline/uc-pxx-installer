UC-P10 installer

Not reviewed. Do not use this page on a unit. The device buttons are off.

Save the log, then ask for help and give the log.

    What do you want to install? ✓

    Crestron's debug Android. The Crestron firmware stays on the unit as the backup.

    Linux in place of the Crestron firmware. All settings and data on the unit are erased.

    Which system?

    Console only needs an SSH key: the next step asks for it.

    Before you start, do these steps. The installer cannot do them for you.

    On the unit's Crestron web page:

    At your router:

    Here:

    Get the files ✓

    The page downloads what it needs. You can go on while it downloads.

    Installer

    Download it from GitHub  

    Mainline Linux

    Crestron userdebug firmware file (pcdfw-1.0.0.94-userdebug.bin)

    Download it from Crestron  

    Crestron may remove this link at any time. Keep a copy of the file.

    Optional: your SSH public key, for logging in over the network. Without one, ssh stays off. You can add it later on the unit's setup page (Access).

    With a key you can log in to the new system as root over your network. Paste the one line of your .pub file, or choose the file. Never use a private key.

    Put the unit in download mode ✓

    1. 1. Connect the unit's USB-C port to this computer.
    2. 2. Power on the unit. The LED cycles red, green, blue, white, then after a few seconds blinks green.
    3. 3. When the LED blinks green, press and hold Vol− and Mic Mute (the Mic key, not the speaker key). The unit restarts: the LED cycles the colours again, then the screen stays on the Crestron logo. That logo screen is download mode.
    4. 4. Press "Connect to the unit" and choose the unit in the list.

    Unit found: UC-P10.

    Windows: the first time on this computer

    Windows needs a USB driver for the unit in this step, once per computer.

    1. 1. Leave the unit as it is now.
    2. 2. Start Zadig.
    3. 3. In Zadig, choose Options, then List All Devices.
    4. 4. In the list, choose the device with USB ID 2207 330C.
    5. 5. Choose WinUSB as the driver, then press Install Driver (or Replace Driver).
    6. 6. When Zadig says that the driver is installed, press Connect to the unit again.
    Linux: the first time on this computer

    Your user needs access to the unit in this step and in the next one. Add these two lines to a udev rule file, for example /etc/udev/rules.d/51-uc-p10.rules:

    SUBSYSTEM=="usb", ATTR{idVendor}=="2207", ATTR{idProduct}=="330c", MODE="0660", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", ATTR{idProduct}=="d00d", MODE="0660", TAG+="uaccess"

    Then run sudo udevadm control --reload-rules, disconnect the cable and connect it again.

    Start the installer ✓

    The unit restarts. Keep it connected.

    Linux: before you start the installer

    The installer uses one more USB device. Add this line to the same udev rule file before you press Start the installer. The line also stops ModemManager from using the unit:

    SUBSYSTEM=="usb", ATTR{idVendor}=="1d6b", ATTR{idProduct}=="0105", ENV{ID_MM_DEVICE_IGNORE}="1", MODE="0660", TAG+="uaccess"

    Then run sudo udevadm control --reload-rules.

    Windows: the first time on this computer

    Windows needs a USB driver for the unit in this step, once per computer.

    1. 1. Leave the unit as it is now.
    2. 2. Start Zadig.
    3. 3. In Zadig, choose Options, then List All Devices.
    4. 4. In the list, choose the device with USB ID 18D1 D00D.
    5. 5. Choose WinUSB as the driver, then press Install Driver (or Replace Driver).
    6. 6. When Zadig says that the driver is installed, press Connect again.

    Install ✓

    On the unit, press OK when it asks a question, and hold OK for 3 seconds where the screen says Hold.

    The unit shows the install plan. Hold OK (the Mic key) for 3 seconds to start the install.

    Bootloader unlocked.

    Unlocking the bootloader. Do not disconnect the power.

    Installing. Do not disconnect the power.

    The unit is working. Do not disconnect the power.

    Done. The unit restarts.

    The install was canceled on the unit. Nothing was written.

    The unit did not install. Nothing was written. Save the log and ask for help.

    KEEP THE UNIT POWERED. Do not restart it. Save the log and ask for help.

    If the unit's screen says Stopped or Keep the unit powered: do not disconnect the power. Save the log and ask for help.

    Install the system ✓

    The unit needs an internet connection now.

    Waiting for the unit …

    When the unit's screen asks for the computer, press Connect and choose the unit.

    Checking the system

    The unit cannot download the packages. Check the unit's network cable. It tries again by itself.

    The unit could not download the packages. Send them over the cable instead.

    Download from GitHub  

    The system on the unit is not as expected. Save the log and ask for help.

    Step 2 starts on the unit by itself. To stop it, press Back on the unit.

    Step 2 runs on the unit. Do not disconnect the power.

    The unit restarts.

    The unit did not start step 2. Nothing was written. Save the log and ask for help.

    Step 2 was stopped on the unit. Nothing was written. Restart the unit to see the question again, then hold OK for 3 seconds to start.

    KEEP THE UNIT POWERED. Do not restart it. Save the log and ask for help.

    Waiting for the unit …

    When the unit's screen asks for the computer, press Connect and choose the unit.

    Finishing on the unit …

    Done. Mainline Linux is installed. You can disconnect the cable.

    The unit did not finish yet. Restart the unit. When it has started, press Send again.

UC-P10 installer: start

Not reviewed. Do not use this page on a unit. The device buttons are off.

Stopped

Working. Do not unplug the unit and do not close this page.

1. Browser

What do you want to install?

Choose one. This only selects which installer the page prepares; nothing is written to the unit by this choice.

Keeps the unit's current system as a fallback and installs Crestron's debug Android into the second slot. You can unlock the unit afterwards (optional). This is the proven, shipped installer.

Replaces Android with mainline Linux. The unit must be unlocked. Not ready yet: the mainline installer is not built, reviewed or pinned, so the button is off until it ships.

2. Installer image

The page starts only an image whose sha256 it knows.

3. Unit in download mode

  1. Connect the unit's USB-C port to this computer.
  2. Power on the unit. The LED cycles red, green, blue, white, then after a few seconds blinks green.
  3. When the LED blinks green, press and hold Vol− and Mic Mute (the Mic key, not the speaker key). The unit restarts: the LED cycles the colours again, then the screen stays on the Crestron logo. That logo screen is download mode.
  4. Press "Connect to the unit" and choose the unit in the list.

The page needs the download mode first: it reads the unit's storage layout, model, A/B state and boot command there. Nothing is written in this step.

The page now writes one boot command to the unit (4 sectors at LBA 49184), reads it back, and restarts the unit into fastboot. The page itself never changes the A/B slots. Restarting into fastboot makes the unit reset both A/B slots to “retry” — this is normal and safe, and at least one slot stays bootable the whole time. The page checks that normal reset before it starts the installer, and the installer sets the slots again.

Copy the firmware to the drive (optional)

    
When the installer is running, it shows a drive named UC-PXX-INST on this computer. You can
      copy the firmware .bin onto it by hand, or let the page copy and check it for you. The page writes
      only into the folder you choose; it touches nothing on the unit.

    

    

      
 

      
 

      

      
      

    

    
After the copy, eject UC-PXX-INST on your computer before
      you start the install on the unit. The installer refuses a drive that was not ejected cleanly. The manual copy is
      always available as the fallback.

  


  

    
Unlock the unit (optional)

    
After an Android userdebug install you can unlock the unit. This is optional and is done from your own computer
      over the network (adb), not from this page.
